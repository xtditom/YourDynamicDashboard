# Assets

This folder contains the static visual and audio resources used by YourDynamicDashboard.

- `ai-tools/`, `google-apps/`, `search-tools/`, and `socials/` contain service icons.
- `icons/` contains the extension icons referenced by the browser manifests.
- `badges/`, `promo/`, and `the-showcase/` contain README, store, and showcase graphics.
- `sounds/` contains UI sound assets.

Keep filenames and paths synchronized with the related entries in `src/config.js`, HTML, and CSS files.
